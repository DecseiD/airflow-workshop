# Security Policy

## Supported Use
This repository is intended for local lab/demo usage.

## Reporting a Vulnerability
If you find a security issue in this repository:
1. Do not publish exploit details in a public issue.
2. Contact the maintainer privately first.
3. Include reproduction steps, affected files, and impact.

## Security Notes for Users
- Do not expose demo credentials to public networks.
- Rotate all credentials before using any part of this repo beyond isolated lab environments.
- Prefer placeholder values in public documentation.
