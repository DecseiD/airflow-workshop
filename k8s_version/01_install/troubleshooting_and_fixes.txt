Deployment Summary: Problems & SolutionsProblem 1: Helm Schema Validation Failures for Environment VariablesDescription: Attempting to inject Azure credentials via Kubernetes Secrets failed because the chart strictly validates env blocks and rejected the extraEnv array format.Solution: We reformatted extraEnv to act as a templated multi-line string using the pipe character (extraEnv: |), allowing Helm to parse the valueFrom secret references correctly.  Problem 2: Version Requirement BumpDescription: The default chart values needed to be updated to a newer release.Solution: We bumped both the defaultAirflowTag and airflowVersion to 2.11.0.  Problem 3: Pods Stuck in Pending State (Storage Conflict)Description: The scheduler, triggerer, and webserver pods hung in a Pending state. They were waiting for a shared log volume (PVC), but the default Azure managed disks strictly support ReadWriteOnce (RWO), causing a conflict with Airflow's ReadWriteMany (RWX) request.Solution: To proceed quickly for the workshop, we bypassed the storage class conflict by disabling log persistence entirely (logs.persistence.enabled: false).  Problem 4: External Reachability on AKSDescription: The UI was inaccessible from the open internet because the NGINX ingress controller was not provisioned, leaving the cluster defaulting to internal ClusterIP services and a local airflow.local host.Solution: We exposed the UI directly to the internet by changing the webserver service type to LoadBalancer.  Problem 5: Entra ID (OAuth) Sign-In DenialsDescription: Following a successful Microsoft login, Flask-AppBuilder (FAB) rejected the user session. This was caused by manual endpoint misconfigurations, role synchronization crashes, and missing profile claims.Solution: We refactored the webserverConfig to utilize OIDC Auto-Discovery via the server_metadata_url. We also disabled automatic role mapping (AUTH_ROLES_SYNC_AT_LOGIN = False) and manually added the email claim to the Azure App Registration token configuration to satisfy FAB's user creation requirements.
